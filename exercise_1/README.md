## 2

1. Corrective Maintenance

Replacing a broken conveyor belt after failure.

Repairing a centrifugal pump after a seal failure.

Replacing damaged seals in a leaking hydraulic cylinder.

2. Planned (Scheduled) Maintenance

Changing gearbox oil every 4,000 operating hours.

Servicing an HVAC system every six months.

Lubricating CNC machine components at scheduled intervals.

3. Condition-Based Maintenance

Replacing motor bearings when vibration exceeds a set limit.

Changing hydraulic filters when oil contamination becomes excessive.

Inspecting a gearbox when its temperature exceeds a threshold.

4. Predictive Maintenance

Predicting bearing failures using vibration data and machine learning.

Forecasting wind turbine gearbox failures using sensor data.

Predicting centrifugal pump failures using historical operating data.
